# WebSite Generator
## Che cos'è?
Genera siti web semplici attraverso una semplice interfaccia.
### Non sai da dove iniziare?
Utilizza uno dei template pronti per essere personalizzati!
## Funzionalità Disponibili
- Integra i **widget** della raccolta per rendere il tuo sito più dinamico
- Utilizza l'**assistente AI** integrato per ricevere consigli sulla UI/UX e correggere errori
- Utilizza l'**Assistente Accessibilità Web** che verifica se il sito web è conforme ai reggolamenti Europei per l'accessibilità
- Utilizza uno dei **template** disponibili per realizzare il tuo sito web
